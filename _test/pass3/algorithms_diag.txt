# Algorithm registry for this shader directory (read by GpuSort at startup).
#
#   algorithm <name>
#   dispatch <file.hlsl> <entryPoint> <groupSize> [NAME=VALUE ...]
#
# Each 'dispatch' line is one ExecuteIndirect(DISPATCH {numSorts, 1, 1}) of that shader, compiled
# at runtime for cs_6_6 with -O3. The framework always adds -D GROUP_SIZE=<groupSize> and
# -D WAVE_SIZE=<device WaveLaneCountMin> (plus WAVE_SIZE_REQUIRED=1 if the device reports a range of
# wave sizes; see common.hlsli); extra NAME=VALUE tokens become further defines (e.g. the size tier
# bounds MIN_COUNT / MAX_COUNT).
# One group handles one sort (SV_GroupID.x = sort index). The dispatches of an algorithm are
# issued back-to-back WITHOUT barriers, so each one must early-out for sorts outside its tier.
#
# Bindings (see common.hlsli): b0 root constants, t0 sort descriptors, t1 input, u0 output.
#
# pass3 DIAGNOSTIC set (smoke run): references, per-path curves, combinations, microbenchmarks.
