# FINAL algorithm set: every distinct sort algorithm of pass0..pass7, run from the current shaders\
# (GpuSort.exe --algo-file algorithms_final.txt; run_all.bat final). See _test/pass7/notes.md,
# "Final set", for how it was built and what to read from it.
#
#   algorithm <name>
#   dispatch <file.hlsl> <entryPoint> <groupSize> [NAME=VALUE ...]
#   flush <mode>        optional: overrides --flush-mode for this algorithm (see --help)
#   pass <N>            optional: the pass (_test/passN) that introduced the algorithm (CSV column pass)
#   desc <text>         optional: one-line description, to the end of the line (CSV column description;
#                       no '#' in it, that starts a comment)
#   tag <word> [...]    optional: tags (CSV column tags, ';'-separated), e.g. rec_discrete
#
# Selection: the union of the algorithm lists of _test/pass0,1,2,3,4,5,7 (algorithms.txt) plus the
# sort configurations that only the diagnostic lists had (_test/pass3 and pass4 algorithms_diag.txt:
# per-path curves and tier combinations, marked "diag set" below), deduplicated by identical dispatch
# lists (same shader file, entry point, group size and defines, in any define order), and then by
# identical compiled code: s4_radix2 (pass4) = s3_radix2_k8, s3_bitE8 / s4_bitE8 (diag) = s1_bitreg,
# s3_rank1024_bitE8 (diag) = s1_rank1024_bitreg compile to the same DXIL at wave16 / 32 / 64 (other
# shader files, same code), so only the older name is kept. Each algorithm is listed once, under the
# pass that introduced it. Left out: the pass3 / pass4 microbenchmarks (ub_*: a
# synthetic prelude before the sort), the validation-only variants (pass4 v64_*, pass7 v_*_span:
# SHUFFLE_SPAN_TEST=1, the same algorithms with the shuffle span halved), and the flush-mode variants
# except the five of the reference below (the method story; pass5 / pass6 diag sets: the others).
# All shader files are the current ones: every snapshot's shader files are identical to shaders\
# (git blob hashes) except common.hlsli (pass0-pass4: comments, and pass0/pass1 lack the WAVE_SIZE /
# SHUFFLE_SPAN defines, additions only) and ubench.hlsli (pass3: microbenchmarks only).
#
# Flush mode: the default (full_d50 since the final set: 256 MB flush, then a ~50 us ALU spin drain;
# see --help) unless a 'flush' line says otherwise.
#
# Short names used in the descriptions: R = rank sort (1 element per thread unless xN), B<E> =
# register/wave bitonic with E elements per thread, LDS bitonic = the pass0 bitonic, P = pass2 LDS
# radix (1024 threads, 32 KB), radix2 / radix3 = the pass3 / pass4 radix variants, X = pass7 ballot
# radix, @n = threads per group, m<k>_ = k dispatches (one per size tier), s<pass>_ = one dispatch.
#
# Recommended configurations (tags): rec_discrete = s1_rank512_bitreg2048_radix (one dispatch; the
# best or within noise of the best on the RTX 5080 and RX 7900 XTX, no multi-dispatch cost);
# rec_integrated = m4_b128_p (4 tier-sized dispatches; best complete configuration on the Ryzen iGPU,
# see _test/pass7/notes.md "AMD results").
